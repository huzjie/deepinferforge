# 提示词模板：实现投机解码

## 模板

```
请实现「草稿-验证」式投机解码的加速比模型（Leviathan）。

要求：
1. 写出期望每轮产出 token 数 expected = (1 - a^(g+1)) / (1 - a) 的推导；
2. 写出 wall-clock 加速比 speedup = expected / (1 + g*c) 并解释 c 的含义；
3. 说明 a → 1 时的极限行为；
4. 给出接受率 a、草稿长度 g、成本比 c 对加速比的三维影响分析。

输出：公式推导 + 伪代码 + 数值示例。
```

## 为什么这样写

- 明确要求「推导」而非「背诵公式」，防止把公式方向写反（分母是草稿+验证成本）。
