# 提示词模板：分页 KV Cache

## 模板

```
请设计一个分页（paged）KV Cache，服务百万 token 长上下文的多序列并发推理。

要求：
1. 定义固定大小 block + 每序列 block table 的数据结构；
2. 给出 alloc / free / evict 的伪代码（LRU 优先）；
3. 说明分页如何避免碎片化、如何支持序列间共享与逐序列回收；
4. 给出一个并发序列满载触发驱逐的示例。

输出：数据结构定义 + 伪代码。
```

## 为什么这样写

- 分页的核心价值是「无碎片 + 可驱逐」，把这两点显式列为要求。
