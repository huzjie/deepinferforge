# 提示词模板：为跨平台推理框架设计统一 IR

## 模板

```
你是一名推理编译器架构师。请为「一份模型、同时编译到 NVIDIA CUDA 与华为昇腾 CANN」
的推理框架设计中间表示（IR）。要求：

1. 明确 IR 的抽象层级（算子级/张量级/指令级）并说明理由；
2. 定义算子集合与 dtype 枚举（含低精度 fp8/int4 的跨平台差异处理）；
3. 说明「图优化 pass」如何做到平台无关；
4. 给出一个 3-5 算子的示例图（matmul->add->relu）的 IR 表示。

约束：不引入任何第三方框架；输出可直接落地的伪代码 + 数据结构定义。
```

## 为什么这样写

- 「抽象层级 + 理由」逼出真正的设计权衡，而不是空泛的「用图表示」。
- 「低精度跨平台差异」是统一框架最容易翻车的点，提前点出来。
- 「平台无关 pass」把难点从「怎么优化」转成「在哪一层优化」。
