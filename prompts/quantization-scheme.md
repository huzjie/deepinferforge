# 提示词模板：设计对称量化方案

## 模板

```
请为一个大模型权重设计对称后训练量化（PTQ）方案，覆盖 INT8 / FP8-e4m3 / W4A4 三档。

要求：
1. 给出每种方案的 scale 计算与量化/反量化公式；
2. 说明 fp8-e4m3 的符号位/指数/尾数拆分与 clamp 范围；
3. 说明 W4A4 group-wise 的 group_size 如何权衡精度与内存；
4. 设计一个「量化质量」度量（往返误差），并说明它如何随校准质量单调变化。

输出：公式 + 伪代码 + 一张三档对比表。
```

## 为什么这样写

- 「往返误差随校准质量单调」把评测目标变成可证伪的命题，逼出干净度量。
